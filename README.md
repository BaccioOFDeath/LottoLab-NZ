# LottoLab NZ

Independent Lotto NZ historical draw dashboard, not affiliated with Lotto NZ.

## Status
This is a **first public preview**, not a complete or automatically updated result service. The archive contains 15 seed entries (2 September–21 October 2026) which require independent production verification. Results may be stale. Never use this site to validate a ticket or prize claim; use [MyLotto](https://mylotto.co.nz).

## Hosting
On GitHub go to **Settings → Pages → Build and deployment → Deploy from a branch → main → / (root) → Save**. Expected URL: https://baccioofdeath.github.io/LottoLab-NZ/

## Planned
- Historical backfill and source provenance
- Fully verified scheduled result retrieval and publishing
- Powerball, Strike, prize and distribution statistics
- Alerts when source retrieval/validation fails

Historical frequencies do not alter the independent probability of any future draw.
